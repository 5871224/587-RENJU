Renlib 3.7 使用說明

解壓後檔案如下

執行 RenLib37.exe 即可，按左上白紙的按鈕可以開新檔案，資料夾按鈕可以開啟舊檔。
本軟體儲存的副檔名為 lib，副檔名為 lib 的檔案都可以打開，如上圖 I7 和 D4.lib 是內附的浦月花月譜。

磁片按鈕是儲存檔案，再右邊是修改鈕，要按下才可修改檔案。
紅色！可以設定開啟檔案時出現的盤面。
最右邊有 VCF 和 VCT 兩個按鈕，可以計算當前盤面有沒有 VCF 和 VCT，其他按鈕可自行嘗試。

◎修改鈕按下時，才可直接在盤面上打譜、打上注釋或合併棋譜。
◎要刪除分支可以按鍵盤的 Delete。
◎要在盤面上標記則是按住 Ctrl 再點盤面即可，修改標記也是同樣方法。
◎要合併數個棋譜，可以先建立一個資料夾，把要合併的檔案放進去，開啟其中一個檔案，再按左上 File 裡的 Read all，選擇剛才的資料夾後，即可把資料夾裡的棋譜都併進來；記得修改鈕要按下，否則無法選 Read all。
◎右邊的 Comment 欄可以輸入盤面的注釋。
◎看譜時按滑鼠左右鍵可以前進和後退。
