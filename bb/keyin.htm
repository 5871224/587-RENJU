建議用Google Chrome開啟本頁面
※使用說明  
左鍵點棋盤 次一手，編輯模式可落新子，若要PASS一手，可下在左下角
右鍵點棋盤 前一手，手機點棋盤座標文字，也可回前一手
棋盤上方為標題欄，右方為解說欄，編輯模式下可輸入文字
標題不隨盤面改變，解說會隨盤面變動，右下角可拖曳縮放
   
※按鈕說明  
<< 前一個分支，或起始點
< 前一手
> 次一手
>> 次一個分支，或起始點
↻ 重新整理（可跳到起始點）
Share 分享選項開關
　Image 截圖（若只要棋盤截圖，設定選項可隱藏標題及解說欄）
　TinyURL 將代碼欄做成縮網址，上限約６９００字
　Copy 將代碼欄複製到剪貼簿
Edit 編輯模式開關
　A 標記模式開關（左鍵點棋盤：標記。右鍵點或標記欄為空：刪除）
　　ABC/△/↖ 切換並填入預設文字至標記欄
　　Del 清空標記欄
　　標記欄 可手動增減文字
　X 刪除分支
　New 開新檔案（開新分頁）
　！ 設定起始盤面
　↔ 鏡像盤面
　↶ 旋轉90度盤面
　Set 設定選項開關（其他人打開分享棋譜也會是相同設定）
　　Title 標題欄開關
　　Comment 解說欄開關
　　Boradsize 設定棋盤大小（２～１９）
　　① 手順開關
　　NumMinus 設定手順減少值，若減為０以下不顯示
　　NumHide 設定隱藏前幾手手順
